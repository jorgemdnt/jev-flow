# JevFlow feature map

Read `../SKILL.md` for launch/doctor/evidence/cleanup. Each feature separates automated evidence (pure Swift behavior, isolated render, or real local file recognition) from checks requiring a physical key hold and focused field. No screenshot fixture proves live paste. Select every listed entry path when verifying a changed feature.

| User-facing area | Features |
| --- | --- |
| Capture | [Hold to talk](hold-to-talk.md), [double-tap lock](double-tap-lock.md), [silence and dropout](silence-and-dropout.md), [short tap](short-tap.md), [cancel](cancel.md), [input change](input-change.md) |
| Recognition and delivery | [Local Parakeet speech](local-speech.md), [paste and spacing](paste-and-spacing.md), [auto-insert refusal](auto-insert-refusal.md), [formatting](formatting.md), [Jev fallback](jev-fallback.md) |
| Languages | [Language picker and routing](language-onboarding.md), [whisper fallback](whisper-fallback.md) |
| Edit | [Edit chord](edit-chord.md) (both key orders, selection, no selection, changed selection, Electron clipboard fallback) |
| UI | [Cards](cards.md), [History](history.md), [Dictionary](dictionary.md), [Settings and key health](settings.md), [status menu](status-menu.md) |
| Install and access | [Model install](model-install.md), [permissions and caret](permissions.md) |

Live flow: Right Option → capture → final batch recognition → Jev or local fallback → insert or refusal → History. The separate edit chord transcribes an instruction, calls OpenCode, rechecks selection, then replaces only that selection. Map a failure to its first differing stage; keep raw takes/logs private.
